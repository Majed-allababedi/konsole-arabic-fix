# إصلاح الحروف العربية المنفصلة في Konsole

[English](README.en.md)

واجهت مشكلة في Konsole: بعض الحروف العربية كانت تظهر منفصلة، مع أن العربي في باقي النظام كان سليمًا. المشكلة كانت موجودة في الترمنال نفسه، سواء داخل Hermes أو خارجه.

جرّبت إعدادات Word mode أولًا، لكن ما تغيّر شيء. اللي حل المشكلة عندي كان تغيير الخط إلى DejaVu Sans Mono وفتح نافذة Konsole جديدة. الخط مو أجمل خيار بالنسبة لي، لكنه خلّى الحروف متصلة، فبقيت عليه.

أكتب الخطوات هنا للي يواجه نفس المشكلة.

## جهازي وقت التجربة

- Fedora Linux 44 مع KDE.
- Konsole `26.08.1-1.fc44.x86_64`.
- الترميز UTF-8 كان مضبوطًا، والخطوط العربية موجودة أصلًا.

## تغيير الخط

1. افتح Konsole وادخل إلى Settings → Edit Current Profile.
2. من Appearance اختر DejaVu Sans Mono. أنا استخدمت حجم 10، ويمكنك اختيار الحجم المناسب لك.
3. احفظ الإعدادات وافتح نافذة Konsole جديدة بالكامل، وليس مجرد تبويب جديد.
4. جرّب هذا النص:

```sh
printf 'اللغة العربية جميلة
السلام عليكم ورحمة الله وبركاته
'
```

إذا كنت تستخدم Hermes، شغّله في النافذة الجديدة بعد التأكد أن الحروف متصلة.

## إذا الخط غير موجود

تأكد أولًا من الخط الذي يختاره النظام:

```sh
fc-match 'DejaVu Sans Mono:lang=ar' -f '%{family}: %{file}\n'
```

المفروض يظهر اسم DejaVu Sans Mono. إذا ظهر اسم مختلف، قد يكون النظام اختار خطًا بديلًا.

على Fedora تستطيع تثبيته بهذا الأمر:

```sh
sudo dnf install dejavu-sans-mono-fonts
```

## التعديل من ملف البروفايل

إذا تفضّل تعديل الملف يدويًا، ملفات Konsole تكون عادة هنا:

```text
~/.local/share/konsole/*.profile
```

تأكد أنك تعدّل البروفايل الذي تستخدمه، وخذ نسخة احتياطية منه. داخل قسم `[Appearance]` أضف أو عدّل هذا السطر:

```ini
Font=DejaVu Sans Mono,10,-1,5,50,0,0,0,0,0
```

لا تستبدل الملف كاملًا، ولا تكرر قسم `[Appearance]`. احتفظ بإعدادات الألوان والشفافية وباقي خياراتك. وضعت [مثالًا صغيرًا](examples/arabic-font.profile) لتوضيح الإعدادات فقط.

## إعدادات Word mode

هذه الإعدادات كانت مفعّلة عندي عندما اشتغل الخط:

```ini
WordMode=true
WordModeAttr=true
```

تفعيلها وحده لم يحل المشكلة. أبقيتها مفعّلة بعد تغيير الخط، لذلك هذه هي الإعدادات التي جرّبتها فعلًا؛ لم أختبر النتيجة نفسها مع تعطيلها.

خيار `WordModeAttr` يجعل الكلمة تُرسم بنفس اللون والتنسيق حتى نهايتها، وقد يؤثر على التلوين داخل الكلمات. لو تغيير الخط وحده كفاك، لا تحتاج لتغيير كل إعدادات البروفايل.

## ملاحظات من التجربة

ما احتجت لتغيير لغة النظام أو خطوط بقية التطبيقات. المشكلة كانت في عرض النص داخل Konsole، لا في النص العربي نفسه.

إذا أردت الرجوع، اختر الخط السابق من إعدادات البروفايل أو استعد النسخة الاحتياطية، ثم افتح نافذة جديدة. وإذا بقيت الحروف منفصلة، راجع اسم البروفايل والخط الفعلي قبل تجربة تغييرات إضافية.

بعض الحروف، مثل ا ود ور، لا تتصل بالحرف الذي يليها بطبيعتها. المقصود هنا انقطاع الاتصال في مواضع يفترض أن تكون متصلة.

هذه تجربتي على الجهاز المذكور أعلاه. لا أضمن أن نفس الإعدادات ستعالج كل مشكلة عربية في كل ترمنال.
